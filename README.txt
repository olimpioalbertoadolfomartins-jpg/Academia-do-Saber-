ACADEMIA DE SIMULADOS — ORTOPROTESIA
==========================================

Projeto offline em HTML/CSS/JavaScript.

Incluído:
- Banco de 50 questões baseado no conteúdo fornecido.
- Conteúdo específico de Ortoprotesia separado dos conteúdos transversais.
- Conteúdos transversais presentes apenas em questões próprias: Censo 2024, IIMS 2023–2024, Divisão Político-Administrativa, Ética Profissional e Inteligência Artificial.
- Alternativa escolhida permanece marcada quando se navega entre questões.
- As letras A/B/C/D acompanham a posição atual das alternativas; a escolha não é perdida.
- Cronómetro de 60 minutos.
- Navegação anterior/próxima.
- Resultado, percentagem, erros e revisão com explicações.
- Impressão/Guardar como PDF pelo próprio navegador.
- Funciona sem internet.

IMPORTANTE SOBRE "ENCRIPTAÇÃO"
------------------------------
Não existe encriptação real de um banco de perguntas que precisa ser executado no navegador.
O código cliente pode ser inspecionado pelo utilizador. Este pacote não contém senhas reais.
Para um concurso protegido, o banco de questões deve ficar num servidor/API com autenticação,
e o navegador deve receber apenas o que for necessário.

COMO USAR
---------
1. Extraia o ZIP.
2. Abra index.html no navegador.
3. Escolha a quantidade de questões (1–50).
4. Clique em "Iniciar".
5. Para gerar PDF, clique em "Imprimir / Guardar PDF" e selecione "Guardar como PDF".

OBSERVAÇÃO
----------
As informações de Censo, divisão político-administrativa e IIMS devem ser conferidas nas
fontes oficiais antes de publicar uma versão definitiva para concurso.
